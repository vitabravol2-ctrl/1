# Local AI Trading Terminal v0.1.0 (FOUNDATION)

Локальный прототип торгового терминала с AI-оператором в **DRY-RUN** режиме.

## Запуск
1. Откройте папку `Terminal`.
2. Запустите `START.bat`.
3. Скрипт установит зависимости (если нужно), запустит сервер и откроет `http://localhost:3000`.

## Что такое DRY-RUN
DRY-RUN — это симуляция торговли без реальных ордеров и без подключения Binance trading API.

## Почему LIVE заблокирован
В версии `v0.1.0` liveTradingEnabled принудительно отключён. Это защита от случайной реальной торговли.

## Примеры команд в чат
- `какие стратегии предложишь`
- `проанализируй пару`
- `включи скальпинг в обе стороны с профитом 0.2%`
- `риск 30`
- `останови стратегию`
- `покажи статус`

## Отчёт для Codex
Нажмите **Create report** — терминал сформирует структурированный отчёт для следующей итерации разработки.
